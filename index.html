2025 — LangGraph · Gemini · FastAPI · PostgreSQL

NL2SQL multi-agent system

Business teams needed answers from relational databases without waiting on a SQL-literate analyst. I built a pipeline of specialized agents — schema retrieval, query generation, validation, and a critic that re-evaluates and repairs broken SQL before it ever executes.

Embedding-based schema retrieval surfaces only the tables relevant to each question, which keeps the model's context small on wide databases. Semantic caching short-circuits repeat queries, so similar questions stop triggering redundant LLM calls. Shipped as a REST API over PostgreSQL, handling multi-table joins and aggregations from plain-English input.

Compliance teams work against regulator circulars — RBI, SEBI — that change constantly, and missing an update carries real risk. I architected a multi-service RAG platform on AWS: asynchronous S3→SQS ingestion, hybrid retrieval fusing Pinecone vector search with Elasticsearch keyword search via reciprocal rank fusion, then BGE reranking and context compression before generation.
